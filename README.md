# Site officiel Memory Photos PRO

Ce dépôt contient le site statique indépendant destiné à remplacer les liens SuperNinja/NinjaTech actuellement utilisés dans la politique de confidentialité et la demande de suppression de compte.

## Pages

- `index.html` : politique de confidentialité ;
- `delete-account.html` : procédure de suppression de compte ;
- `online-safety.html` : règles du mode En ligne, signalement et modération.

## Publication via GitHub Pages

1. Garder ce dépôt sous le compte GitHub propriétaire de Memory Photos PRO.
2. Dans **Settings → Pages**, choisir **GitHub Actions** comme source de publication.
3. Rendre le dépôt public, si GitHub Pages n'est pas disponible pour les dépôts privés du compte.
4. Après la première publication, GitHub fournit une URL de type `https://jeromeguex88-ai.github.io/memoryphotos-policy/`.
5. Mettre cette URL à la place des liens SuperNinja dans Google Play Console et, lors de la prochaine version Android, dans l’application.

## Important

Le passage public et l’activation de GitHub Pages sont des actions de publication. Elles ne doivent être faites qu’après validation du texte affiché par le propriétaire.
